# Vector & Quaternion cho quadcopter / for quadcopters

Trang web song ngữ (Tiếng Việt / English) giải thích hệ tọa độ, vector và quaternion dùng trong bộ điều khiển bay quadcopter, kèm hình minh họa và demo 3D tương tác.

A bilingual (Vietnamese / English) page explaining coordinate frames, vectors and quaternions used in quadcopter flight controllers, with illustrations and an interactive 3D demo.

- `index.html` — nội dung / content (`<span lang="vi">` + `<span lang="en">`)
- `css/style.css` — giao diện, sáng/tối / styling, light/dark
- `js/i18n.js` — chuyển ngôn ngữ, mục lục, công thức / language switch, TOC, math
- `js/rotation-demo.js` — demo 3D (three.js)
- `img/` — hình SVG / SVG figures

Chạy thử / Run locally:

```bash
python -m http.server 8000
```

Lấy cảm hứng từ chương «Вектор, кватернион» của Oleg Kalachev tại https://quadcopter.dev/geometry.html. Nội dung ở đây được viết mới độc lập, không phải bản dịch chính thức.
